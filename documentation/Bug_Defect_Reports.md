## Severity Definitions

| Severity | Description | Examples |
|---|---|---|
| Critical | System crash or data corruption | Cannot login, stock wrongly deducted, audit log not recorded |
| High | Major functionality broken | Cannot dispense drugs, PO cannot be created |
| Medium | Partial functionality issue | Report format incorrect, wrong filter result |
| Low | Cosmetic or minor issue | UI alignment, typo, non-critical warning |
